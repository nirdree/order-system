## Orders Page - Quick Start Guide

### What's New?
A fully-featured, production-level orders management page at `/owner/orders` with:
- ✅ Real-time auto-refresh (every 3 seconds)
- ✅ Advanced filtering and search
- ✅ Frontend & backend pagination
- ✅ Status updates without page refresh
- ✅ Order cancellation
- ✅ Live order metrics
- ✅ Mobile responsive design

---

## Key Features Overview

### 1. Real-Time Updates
- Orders automatically refresh every 3 seconds
- No need to manually refresh the page
- Auto-refresh indicator at the bottom shows status

### 2. Filtering System
Click **"Show Filters"** to access:
- **Search by Order ID**: Find specific orders quickly
- **Order Status**: Filter by pending, preparing, served, or cancelled
- **Order Type**: Dine-in or counter orders
- **Placed By**: Staff or customer placed orders
- **Items Per Page**: 5, 10, 15, or 20 orders per page
- **Reset Filters**: Clear all filters with one click

### 3. Order Cards
Each order shows:
- Order ID and current status (with color coding)
- Timestamp
- Quick stats: Duration, Items count, Total price, Order type

**Click the arrow to expand** and see:
- Detailed item list with quantities and prices
- Special instructions and customer notes
- Table/session information
- Complete status history
- Action buttons

### 4. Status Updates
**Two-step process (no page reload):**
1. Expand an order card
2. Click **"✓ Update Status"** to move order to next stage
   - Pending → Preparing → Served
   - Cannot update served or cancelled orders

### 5. Cancel Orders
1. Expand the order card
2. Click the **"Cancel"** button (red trash icon)
3. Confirm cancellation in the dialog
- Can only cancel pending or preparing orders
- Served/cancelled orders cannot be cancelled

### 6. Pagination
Use the **Previous/Next buttons** at the bottom to navigate between pages
- Shows current page, total pages, and total records
- Buttons auto-disable at first/last page

### 7. Dashboard Metrics
Header shows:
- 📊 Total orders count
- ⏳ Pending orders count

## Troubleshooting

### Orders not showing up?
- Check filters - reset them using "Reset Filters" button
- Try refreshing or waiting for auto-refresh
- Check search term if using search

### Can't update order status?
- Make sure order isn't already served or cancelled
- Check permissions (owner/manager/staff required)
- Try refreshing the page

### Status update failed?
- Check your internet connection
- An error message will appear - read it carefully
- Click the X to dismiss and try again

### Auto-refresh stopped?
- Indicator at bottom shows refresh status
- If it stops, refresh the page manually
- Browser tab may have been backgrounded

## Best Practices

1. **Regularly check pending orders** - Monitor the pending count in header
2. **Expand only when needed** - Keeps page responsive
3. **Confirm before cancelling** - Dialog prevents accidents
4. **Use filters effectively** - Narrow down orders for faster processing
5. **Check status history** - See who updated and when

## API Integration

The page uses these endpoints:
- `GET /api/orders` - Fetch orders with filters & pagination
- `PUT /api/orders/{id}` - Update order status
- Auto-polling every 3 seconds for new/updated orders
